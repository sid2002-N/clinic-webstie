The design must feel like a premium startup product (similar to Stripe, Notion, Linear), not a generic admin dashboard.

🎨 DESIGN STYLE
Clean, minimal, high-end SaaS UI
Primary color: Deep blue (#1E3A5F)
Accent color: Kerala green (#2D7D46)
Background: soft light gray (#F8FAFC)
Typography: Inter or Poppins
Use soft shadows, rounded corners (12px–16px), and subtle gradients
Smooth transitions and micro-interactions
Avoid clutter — strong visual hierarchy
📱 MOBILE-FIRST APPROACH
Design for mobile first, then scale to desktop
Replace tables with card-based layouts on mobile
Bottom navigation bar (mobile):
Home
Leads
Messages
Settings
Desktop: sidebar navigation (collapsible)

Action buttons

🧠 UX PRINCIPLES
Prioritize clarity over density
Show most important info first (lead score, intent)
Reduce clicks — quick actions visible
Use color to guide decisions
Make premium features visually desirable (locked but attractive)
🎯 FINAL GOAL

The UI should feel:

Premium and modern
Fast and intuitive
Mobile-friendly for Indian users
Focused on helping colleges act quickly on leads

Avoid generic admin dashboard designs. Make it feel like a polished SaaS product ready for real customers.
