Build a complete multi-tenant SaaS platform called "EduLeads Kerala" — a lead management and communication platform for colleges and education agencies in Kerala, India. The platform connects students seeking college admissions with colleges and agencies looking for qualified leads.

TECH STACK

Frontend: React + Tailwind CSS
Backend/Database: Supabase (PostgreSQL + Auth + Realtime)
Payments: Stripe
Language: English UI, but all student-facing content supports Malayalam text display


USER ROLES
There are 4 roles. Each has a completely separate dashboard and navigation.
1. Superadmin
Platform owner. Sees everything across all tenants.
2. College Admin
Owner of a college account. Manages their subscription, team members, and leads.
3. College Staff
Employee under a college admin. Can view assigned leads and chat. Cannot manage billing.
4. Agency Admin
Same as College Admin but lower priority in lead distribution. Marked as "Agency" type in the system.

MULTI-TENANCY
Every college and agency is a separate Tenant. All data is isolated per tenant. A college admin can only see their own leads, their own team, and their own billing. Use Supabase Row Level Security (RLS) to enforce this at the database level.

LEAD SCORING LOGIC
Implement this as a reusable function called calculateLeadScore(leadData) used everywhere a lead is created or updated:
function calculateLeadScore(leadData) {
  let score = 0

  // Intent (max 30)
  if (leadData.intent_level === 'enroll') score += 30
  else if (leadData.intent_level === 'explore') score += 15
  else score += 5

  // Course clarity (max 20)
  if (leadData.course_interest && leadData.course_interest.length > 10) score += 20
  else if (leadData.course_interest) score += 10

  // Budget (max 20)
  if (leadData.budget_range && leadData.budget_range !== 'unknown') score += 20
  else score += 0

  // Timeline (max 15)
  if (leadData.timeline === 'this_year') score += 15
  else if (leadData.timeline === 'next_year') score += 8
  else score += 2

  // Completeness (max 15)
  const fields = [leadData.full_name, leadData.course_interest,
                  leadData.location, leadData.budget_range,
                  leadData.timeline, leadData.intent_level]
  const filled = fields.filter(f => f && f.length > 0).length
  if (filled === 6) score += 15
  else if (filled >= 4) score += 8
  else score += 2

  const category = score >= 70 ? 'hot' : score >= 40 ? 'warm' : 'cold'
  return { score, category }
}

LEAD ALLOCATION LOGIC
When a new lead is created (manually by admin or later by AI), run this allocation function:

Get all active tenants with quota_remaining > 0
Filter tenants where their preferred courses match the lead's course_interest (or if no preference set, include all)
Sort tenants by priority: colleges before agencies, then by plan (premium=3, pro=2, basic=1), then by quota_used ascending (least used first — round robin effect)
For each tenant in sorted order:

If lead.exclusivity_count >= lead.exclusivity_cap: stop allocating
If tenant.quota_used >= tenant.quota_monthly: skip
Create lead_allocation record
Increment tenant.quota_used by 1
Increment lead.exclusivity_count by 1
Send in-app notification to tenant


Premium tenants: exclusivity_cap for their allocated leads = 1 (exclusive)
Pro tenants: exclusivity_cap = 3
Basic tenants: exclusivity_cap = 5
