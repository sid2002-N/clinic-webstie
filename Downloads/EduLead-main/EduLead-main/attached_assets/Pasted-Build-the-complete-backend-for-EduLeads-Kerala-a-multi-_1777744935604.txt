Build the complete backend for EduLeads Kerala — a multi-tenant SaaS platform connecting Kerala students with colleges via an AI Malayalam counsellor. This is the backend and AI pipeline only. The React frontend is built separately in Lovable and connects to this backend via REST API and webhooks.

TECH STACK

Language: Python 3.11
Framework: Django 4.2 + Django REST Framework
Database: PostgreSQL (connect to Supabase PostgreSQL using the connection string)
Cache / Queue broker: Redis
Async tasks: Celery + Celery Beat
AI: OpenAI GPT-4 API
Speech to text: OpenAI Whisper API
Text to speech: Azure Cognitive Services (Malayalam voice)
Telephony: Twilio (voice calls + WhatsApp Business API)
Payments: Stripe webhooks
Storage: AWS S3 (call recordings, exports)
Auth: JWT tokens (djangorestframework-simplejwt)

pythonclass LeadAllocationService:

    def allocate(self, lead_id: str) -> list:
        """
        Main allocation method. Called after a lead is scored.
        Steps:
        1. Load lead from DB
        2. Get all eligible tenants (active subscription, quota remaining)
        3. Filter by course/location match
        4. Sort by priority: colleges > agencies,
           premium > pro > basic, least quota used first
        5. Allocate to tenants up to lead.exclusivity_cap
        6. For each allocation: create LeadAllocation record,
           decrement quota, send notification
        7. Return list of tenant_ids that received the lead
        """

    def check_quota(self, tenant_id: str) -> dict:
        """
        Returns {'remaining': int, 'used': int,
                 'monthly': int, 'rollover': int}
        Uses Redis for fast checking with DB fallback
        """

    def get_exclusivity_cap(self, plan: str) -> int:
        caps = {'premium': 1, 'pro': 3, 'basic': 5}
        return caps.get(plan, 5)

    def rollover_unused_quota(self, tenant_id: str):
        """
        Called by Celery beat at end of billing cycle.
        Carries unused quota forward, capped at 50% of monthly quota.
        """

    def handle_low_supply(self, lead_id: str):
        """
        When hot leads are insufficient:
        1. Premium clients get remaining hot leads
        2. Fill remaining slots with warm leads for pro/basic
        3. Send notification to lower-tier clients about reduced availability
        """

                            lead_id: str) -> dict:
        """

GET /api/analytics/dashboard/ — overview stats for current tenant
