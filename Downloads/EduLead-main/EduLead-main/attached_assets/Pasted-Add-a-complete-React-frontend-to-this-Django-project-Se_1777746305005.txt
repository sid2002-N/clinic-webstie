Add a complete React frontend to this Django project. Set it up as follows:
Create a new folder called frontend at the root of the project alongside the edulead_backend folder.
Frontend tech stack:

React 18 with Vite
Tailwind CSS for styling
shadcn/ui for components
React Router v6 for navigation
TanStack Query (React Query) for API calls and caching
Zustand for global state (auth token, user info, plan, role)
Axios for HTTP requests with JWT interceptor
Recharts for analytics charts
Socket.io-client or native WebSocket for realtime chat

Setup steps:

Create frontend/ with a Vite + React project
Install all dependencies above
Configure Vite proxy: all /api/ requests proxy to http://localhost:8000 so no CORS issues in development
Configure Tailwind with these brand colours:

Primary: #1E3A5F (deep blue)
Accent: #2D7D46 (Kerala green)
Hot lead: #16a34a (green)
Warm lead: #d97706 (amber)
Cold lead: #6b7280 (gray)


Set up Django to serve the built frontend in production: after npm run build, Django serves index.html from frontend/dist for all non-API routes
Add a concurrently dev script at the root level so one command starts both Django and Vite together:
npm run dev → starts both python manage.py runserver and vite simultaneously

Global state (Zustand store):
javascript// Store these after login — extracted from JWT payload
{
  accessToken: string,
  refreshToken: string,
  userId: string,
  tenantId: string,
  tenantName: string,
  plan: 'basic' | 'pro' | 'premium',
  role: 'superadmin' | 'college_admin' | 'college_staff' | 'agency_admin',
  isAuthenticated: boolean
}
Axios setup with auto-refresh:

Base URL: /api (proxied to Django)
Every request adds Authorization: Bearer {accessToken}
On 401 response: automatically call /api/auth/refresh/ with refresh token, update access token in store, retry original request
On refresh failure: clear store and redirect to /login

/ → Landing page (public)

Route guards:

PublicRoute: redirect to /dashboard if already logged in
PrivateRoute: redirect to /login if not authenticated
AdminRoute: redirect to /dashboard if role !== superadmin
PlanGate component: wraps any feature, shows upgrade prompt if plan requirement not met
